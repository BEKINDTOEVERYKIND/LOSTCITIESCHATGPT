# Objective-3 champion self-play showcases

These three complete games use the Objective-3 actor promoted in
[commit `09aaf8f`](https://github.com/BEKINDTOEVERYKIND/LOSTCITIESCHATGPT/commit/09aaf8fdf50d364c100295dca1e696472353666e).

The seeds were frozen before play. Every completed game is published in the
original plan order, without outcome screening, selection, replacement, or
retry. Each self-contained viewer includes the played policy, the actor's
search, a higher-compute post-game search, belief diagnostics, and evaluation
at every ply.
